# Whitefly Multi Stage Detection Model

This repository contains the notebook for training an object detection model to identify adult and nymph whiteflies.

## Dataset

The dataset is hosted separately, Before running the training notebook in this repository, please download the dataset from:
**https://github.com/AliAhmad-M/MultiStageWhiteflyData**

### Setup Instructions

1. Clone or download the dataset from the [MultiStageWhiteflyData repository](https://github.com/AliAhmad-M/MultiStageWhiteflyData).
2. Place the downloaded dataset files into the root directory of this repository (or update the dataset path inside the notebook to match your local setup).
3. Open and run the notebook to train and evaluate the object detection model.
